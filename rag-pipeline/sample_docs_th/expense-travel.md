# ค่าเดินทาง

ค่าเดินทางต่างจังหวัดเบิกได้ไม่เกินสองพันบาทต่อวัน โดยต้องแนบใบเสร็จตัวจริง

# ค่าที่พัก

ค่าที่พักเบิกได้ตามจริงไม่เกินสามพันห้าร้อยบาทต่อคืน ในกรุงเทพฯ และปริมณฑลไม่อนุญาตให้เบิกค่าที่พัก

# เงินสำรองจ่าย

พนักงานขอเบิกเงินสำรองจ่ายล่วงหน้าได้ไม่เกินห้าหมื่นบาทต่อทริป และต้องเคลียร์ใบเสร็จภายในสิบห้าวันหลังกลับ

# กำหนดเวลาเบิก

ต้องส่งใบเบิกค่าใช้จ่ายภายในสามสิบวันหลังเกิดรายจ่าย ใบเบิกที่ล่าช้าต้องได้รับอนุมัติจากผู้อำนวยการฝ่ายการเงิน
