# ลาพักร้อน

พนักงานประจำมีสิทธิ์ลาพักร้อนสิบวันต่อปี ต้องยื่นคำขอล่วงหน้าอย่างน้อยเจ็ดวันผ่านระบบ HR วันลาที่ใช้ไม่หมดโอนไปปีถัดไปได้ไม่เกินห้าวัน

# ลาป่วย

พนักงานลาป่วยได้สามสิบวันต่อปีโดยได้รับค่าจ้างเต็มจำนวน หากลาติดต่อกันเกินสามวันต้องแนบใบรับรองแพทย์

# การทำงานจากบ้าน

พนักงานทำงานจากบ้านได้สองวันต่อสัปดาห์เมื่อหัวหน้าทีมอนุมัติ ต้องเข้าร่วมประชุมทีมประจำวันทางวิดีโอตามเวลาที่กำหนด

# ประกันสุขภาพ

บริษัทจ่ายเบี้ยประกันสุขภาพกลุ่มให้พนักงานและคู่สมรสหลังผ่านทดลองงาน วงเงินผู้ป่วยในหนึ่งล้านบาทต่อปี

# โบนัส

โบนัสประจำปีจ่ายในเดือนมีนาคม คำนวณจากผลการประเมินและอายุงานของพนักงานแต่ละคน
