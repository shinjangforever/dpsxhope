# การคืนสินค้า

ลูกค้าคืนสินค้าได้ภายในสามสิบวันนับจากวันรับของ เมื่อสินค้าไม่เสียหายและมีหลักฐานการซื้อ

# การคืนเงิน

บริษัทคืนเงินเข้าบัญชีเดิมภายในเจ็ดวันทำการหลังตรวจสอบสินค้าที่ส่งคืน หากชำระด้วยบัตรเครดิตอาจใช้เวลาถึงสิบสี่วัน

# สินค้าเสียหายระหว่างขนส่ง

หากสินค้าแตกหักระหว่างขนส่งให้ถ่ายรูปกล่องและตัวสินค้าส่งภายในสองวัน บริษัทจะส่งสินค้าใหม่ให้โดยไม่คิดค่าใช้จ่าย

# การรับประกัน

สินค้าอิเล็กทรอนิกส์รับประกันหนึ่งปีนับจากวันซื้อ ไม่ครอบคลุมความเสียหายจากน้ำและการตกกระแทก
