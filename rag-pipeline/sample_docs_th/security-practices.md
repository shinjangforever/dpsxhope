# รหัสผ่าน

รหัสผ่านต้องยาวอย่างน้อยสิบสองตัวอักษร ห้ามใช้ซ้ำกับบริการอื่น และเปลี่ยนทุกเก้าสิบวัน

# การยืนยันตัวตนสองชั้น

ทุกบัญชีที่เข้าถึงข้อมูลลูกค้าต้องเปิดการยืนยันตัวตนสองชั้น ห้ามส่งรหัสยืนยันให้ผู้อื่นแม้อ้างว่าเป็นเจ้าหน้าที่

# ข้อมูลลูกค้า

ห้ามส่งข้อมูลลูกค้าผ่านแอปส่วนตัวหรืออีเมลส่วนตัว ข้อมูลที่ต้องแชร์ให้ใช้โฟลเดอร์กลางที่ฝ่ายไอทีกำหนดเท่านั้น

# อีเมลหลอกลวง

หากพบอีเมลที่ขอรหัสผ่านหรือให้กดลิงก์ที่น่าสงสัย ให้ส่งต่อไปยังที่อยู่ security ของบริษัทและห้ามกดลิงก์
