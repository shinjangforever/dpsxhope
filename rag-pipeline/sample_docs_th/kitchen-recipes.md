# ต้มยำกุ้ง

ต้มน้ำกับตะไคร้ ข่า และใบมะกรูดประมาณห้านาที ใส่กุ้งสดต้มต่ออีกสามนาทีจนสุก ปรุงรสด้วยน้ำปลา น้ำมะนาว และพริกขี้หนูบุบ

# ผัดกะเพรา

ผัดกระเทียมกับพริกให้หอม ใส่เนื้อสับผัดจนสุก ปรุงด้วยซอสหอยนางรมและซีอิ๊วดำ ใส่ใบกะเพราปิดท้ายแล้วปิดไฟทันที เสิร์ฟพร้อมไข่ดาว

# ข้าวเหนียวมะม่วง

นึ่งข้าวเหนียวประมาณสามสิบนาที คลุกกับกะทิที่ผสมน้ำตาลและเกลือขณะข้าวยังร้อน ราดหน้าด้วยกะทิข้นและเสิร์ฟกับมะม่วงสุก
