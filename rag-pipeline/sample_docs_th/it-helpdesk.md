# รีเซ็ตรหัสผ่าน

ผู้ใช้รีเซ็ตรหัสผ่านเองได้ที่หน้า SSO โดยยืนยันตัวตนผ่านแอปในมือถือ หากเข้าแอปไม่ได้ให้โทรแจ้งฝ่ายไอทีที่เบอร์ต่อ 1100 ในเวลาทำการ

# VPN

การเชื่อมต่อ VPN ต้องใช้ใบรับรองเครื่องที่ฝ่ายไอทีติดตั้งให้ ใบรับรองหมดอายุทุกสิบสองเดือนและต้องต่ออายุก่อนหมดอายุสองสัปดาห์

# ขอติดตั้งซอฟต์แวร์

ซอฟต์แวร์นอกรายการมาตรฐานต้องส่งคำขอผ่านระบบตั๋วและรอหัวหน้าฝ่ายอนุมัติ ใช้เวลาประมาณสามวันทำการ

# อุปกรณ์สูญหาย

หากโน้ตบุ๊กหรือมือถือสูญหายต้องแจ้งฝ่ายไอทีภายในหนึ่งชั่วโมง เพื่อล็อกอุปกรณ์จากระยะไกลและลบข้อมูลบริษัท
