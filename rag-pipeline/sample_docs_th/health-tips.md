# การนอนหลับ

ผู้ใหญ่ควรนอนหลับเจ็ดถึงเก้าชั่วโมงต่อคืน และเข้านอนเป็นเวลาเดิมทุกวันเพื่อให้นาฬิกาชีวภาพคงที่

# การดื่มน้ำ

แนวทางที่พบบ่อยคือดื่มน้ำสะอาดวันละแปดแก้ว ในวันที่อากาศร้อนหรือออกกำลังกายหนักควรเพิ่มปริมาณ

# การออกกำลังกาย

องค์การอนามัยโลกแนะนำให้ออกกำลังกายระดับปานกลางอย่างน้อยหนึ่งร้อยห้าสิบนาทีต่อสัปดาห์

# ตรวจสุขภาพประจำปี

ควรตรวจสุขภาพประจำปีปีละหนึ่งครั้ง โดยเฉพาะผู้ที่อายุเกินสี่สิบปีควรตรวจระดับน้ำตาลและความดันโลหิต
