# languages

Code samples และ patterns ในหลายภาษา — แสดง AI engineering patterns ข้ามภาษา

## ภาษาที่รองรับ

| ภาษา | โฟลเดอร์ | จุดเน้น |
|------|---------|---------|
| Go | `go/` | concurrent HTTP server, CLI tools |
| Rust | `rust/` | tokenizer, performance-critical processing |
| TypeScript | `typescript/` | type-safe LLM client, API types |
| Bash | `bash/` | automation scripts, pipeline orchestration |
| SQL | `sql/` | vector similarity queries, metadata filtering |
| YAML | `yaml/` | config schemas, CI/CD pipelines |

## แนวคิด

แต่ละภาษาแสดง pattern เดียวกัน (เช่น LLM API call, data processing)
เพื่อให้เห็นความต่างของ idioms แต่ละภาษา
