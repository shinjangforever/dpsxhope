# บทเรียนสาย หุ่นยนต์

คำถามของสายนี้: คำสั่งจากโมเดลกลายเป็นการเคลื่อนที่ที่ปลอดภัยได้อย่างไร

ทำตามลำดับจากระดับ 1 แต่ละระดับมีขั้นที่ต้องทำ สิ่งที่ควรเห็น และเกณฑ์ว่าผ่าน รันคำสั่งทั้งหมดจาก root ของ repo ภาพรวมของสายอยู่ที่ [PATHS.md](../PATHS.md) และคำอธิบายเครื่องมืออยู่ที่ [TOOLS.md](../TOOLS.md)

ดูใน terminal: `python hope.py stack learn robotics`

## ระดับ 1 เริ่มใช้

ใช้ของที่มีให้ได้ผล โดยยังไม่ต้องเขียนโค้ด เมื่อจบระดับนี้: รันเดโมและอธิบายได้ว่าแต่ละชั้นทำหน้าที่อะไร

เครื่องมือที่เริ่มใช้: Python, เดโมจากหัวใจสู่กลไก

1. รันเดโม: คำสั่งหนึ่งประโยคถูกส่งผ่านด่านตรวจ ตัวควบคุม มอเตอร์ และกลไก

   ```bash
   python fields/robotics/heart-to-mechanism/simulate.py "ไปที่ 1 เมตร"
   ```

   ควรเห็น: ผลของแต่ละชั้น และตำแหน่งสุดท้ายใกล้ 1 เมตร
2. สั่งให้ไปนอกพื้นที่ทำงาน

   ```bash
   python fields/robotics/heart-to-mechanism/simulate.py "ไปที่ 30 เมตร"
   ```

   ควรเห็น: ด่านตรวจปฏิเสธ ไม่มีการเคลื่อนที่ และรหัสออกเป็น 2
3. ดูว่าเกิดอะไรเมื่อด่านซอฟต์แวร์พังหรือตัวควบคุมค้าง

   ```bash
   python fields/robotics/heart-to-mechanism/simulate.py --faults
   ```

   ควรเห็น: เทียบกรณีมีและไม่มีชั้นป้องกันของกลไก
4. อ่านบทที่ 1
   ดู: fields/robotics/01-heart-to-mechanism.md

**ผ่านระดับนี้เมื่อ:** อธิบายได้ว่าทำไมด่านตรวจต้องแยกจากโมเดล และทำไมมีด่านซอฟต์แวร์อย่างเดียวยังไม่พอ

## ระดับ 2 ปรับใช้

แก้ค่า เขียนส่วนเล็ก และต่อยอดต้นแบบให้เข้ากับงานของตัวเอง เมื่อจบระดับนี้: เขียนกฎและค่าควบคุมสำหรับกลไกของตัวเองในแบบจำลอง

เครื่องมือที่เริ่มใช้: NumPy, robokit, ด่านตรวจคำสั่ง (robokit gate)

1. วางแผนโปรเจกต์ของคุณ: ตอบห้าคำถาม ได้แผนและไฟล์กฎตั้งต้น

   ```bash
   python hope.py robot plan
   ```

   ควรเห็น: ไฟล์ plan.md และ safety-profile.json
2. ตรวจไฟล์กฎตัวอย่าง

   ```bash
   python hope.py robot gate validate fields/robotics/robokit/profiles/desk-arm-2axis.json
   ```

   ควรเห็น: action ที่อนุญาต เขตห้ามเข้า และขีดจำกัดอัตรา
3. คำนวณระยะหยุด

   ```bash
   python hope.py robot stop --speed 0.5 --react 0.2 --decel 2.0 --available 0.4
   ```

   ควรเห็น: ระยะช่วงตอบสนอง 0.1 m ระยะเบรก 0.0625 m และบอกว่าหยุดทันไหม
4. หาค่า PID เริ่มต้นจากค่าของเครื่อง

   ```bash
   python hope.py robot tune --mass 2 --friction 4 --max-force 40
   ```

   ควรเห็น: ค่า kp, kd และผลทดสอบเมื่อมวลกับแรงเสียดทานคลาดไป 30 %

**ผ่านระดับนี้เมื่อ:** มีไฟล์กฎของกลไกคุณที่ผ่าน gate validate และมีตัวเลขระยะหยุดที่คำนวณจากค่าที่วัดจริง

## ระดับ 3 สร้างระบบ

ทำให้คนอื่นใช้ได้ รันได้ต่อเนื่อง และดูแลต่อได้ เมื่อจบระดับนี้: ทดสอบทั้งระบบในโลกจำลองก่อนต่อฮาร์ดแวร์

เครื่องมือที่เริ่มใช้: Gazebo, MuJoCo

1. ดูสะพานที่ส่งคำตอบของโมเดลเข้าด่านตรวจก่อนเสมอ โดยรันแบบไม่ต้องมีโมเดล

   ```bash
   python domains/robotics/ros2_llm_bridge.py --offline
   ```

   ควรเห็น: คำสั่งบางข้อถูกทำ บางข้อถูกปฏิเสธ บางข้อถูกถามซ้ำ
2. อ่านรายการตัวจำลองและใบอนุญาต แล้วเลือกหนึ่งตัวสำหรับกลไกของคุณ
   ดู: fields/robotics/README.md ตารางเครื่องมือ (คู่มือยังไม่ได้ลอง MuJoCo และ Gazebo)
3. อ่านเช็กลิสต์ก่อนต่อฮาร์ดแวร์
   ดู: fields/robotics/README.md
4. เทียบระยะหยุดจาก robokit กับตัวอย่างภาษา C++ ที่ใช้สูตรเดียวกัน
   ดู: languages/cpp/stop_distance.cpp

**ผ่านระดับนี้เมื่อ:** ทั้งสายจากคำสั่งถึงการเคลื่อนที่ของคุณรันได้ในโลกจำลอง โดยคำสั่งอันตรายถูกปฏิเสธก่อนถึงมอเตอร์

## ระดับ 4 เชี่ยวชาญ

ออกแบบ วัดผล และตัดสินใจเชิงระบบด้วยหลักฐาน เมื่อจบระดับนี้: นำระบบขึ้นฮาร์ดแวร์จริงโดยมีชั้นป้องกันอิสระ

เครื่องมือที่เริ่มใช้: C++, ROS 2, Rust

1. อ่านเส้นทางเรียนขั้น 4 และ 5 ของสาขาหุ่นยนต์ (ROS 2 และฮาร์ดแวร์จริง)
   ดู: fields/robotics/README.md
2. คอมไพล์และรันตัวอย่าง C++ (ต้องมีตัวคอมไพล์ เช่น g++)

   ```bash
   g++ -std=c++17 -O2 -Wall -Wextra -o stop_distance languages/cpp/stop_distance.cpp
   ```

   ควรเห็น: ไฟล์ stop_distance ที่รันด้วยค่าเดียวกับ robot stop แล้วได้ผลตรงกัน
3. อ่านแถว T2 ใน threat model: ด่านซอฟต์แวร์ยังไม่ใช่ชั้นป้องกันอิสระ
   ดู: stack/THREAT-MODEL.md
4. ออกแบบชั้นป้องกันทางกายภาพของกลไกคุณ: ปุ่มหยุดฉุกเฉิน ตัวจำกัดระยะ การตัดกำลัง ซึ่งทำงานได้แม้ซอฟต์แวร์ค้าง

**ผ่านระดับนี้เมื่อ:** มีแผนขึ้นฮาร์ดแวร์ที่ระบุชั้นป้องกันอิสระ และมาตรฐานความปลอดภัยที่ต้องตรวจกับผู้เชี่ยวชาญ (คู่มือนี้ยังไม่เคยต่อกับหุ่นยนต์จริงหรือ ROS 2 จริง)

คำสั่งที่ไม่ต้องใช้โมเดลหรืออินเทอร์เน็ตถูกรันโดยชุดทดสอบของคู่มือทุกครั้งที่มีการแก้ ส่วนขั้นที่ต้องใช้โมเดล ไฟล์ของคุณ หรือการตัดสินใจของคุณ ต้องทำและตรวจด้วยตัวเอง
